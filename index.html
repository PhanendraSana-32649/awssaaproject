Project scope & limitations

  • Dashboard backend: Flask REST endpoints with optional Boto3 CloudTrail integration.
  • Current AWS integration reads events from one configured account/region.
  • Organization-wide aggregation requires an AWS Organizations organization, suitable management-account permissions, and an organization trail with a centralized destination.
  • Sample records are clearly marked and must not be presented as deployed AWS evidence.
